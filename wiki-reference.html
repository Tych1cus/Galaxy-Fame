Where the text and the code disagree read this first

9 places where a card says one thing and the code does another, plus 6 where the card simply leaves something out. Nothing here has been changed — this is the list to work from.

Text contradicts codePlanets

Orbital Factory pays 1 gold with no Asteroid

Text says

“+1 💰, +1 💰 per adjacent Asteroid.” Reads as: 1 gold, and another per Asteroid.

Code does

Code: cr[i] = 1 + asteroids + (ledger?1:0) — a flat 1 gold for existing, then +1 per adjacent Asteroid. Alone it pays 1 (2 with Cosmic Ledger).

Text contradicts codePlanets

Ice Planet’s text promises a bonus it never gets

Text says

“Worth 1 ⭐. Pick a square…” — flat 1 fame, no neighbour bonus mentioned.

Code does

Code gives exactly 1, so the text is right — but the find-odds card still says “+1 ⭐, plus 1 for each neighbouring piece”, which is the Permafrost relic’s effect. Two places, two different stories.

Text contradicts codeRelics

Fame Dividend says +8, code gives +12

Text says

“Reaching a fame goal gives +8 💰 more.”

Code does

Code: divPay = has('dividend') ? 12 : 4. Base goal reward is 4, so the relic adds +8 — the text is actually correct here; the +12 is the total, not the bonus. Worth rewording so nobody reads it as +12 more.

Text contradicts codeRelics

Encore doubles the Chorus’s own worth, not “scores double”

Text says

“The last Chorus to score each spin scores double.”

Code does

Code: if(has('encore') && lastH > -1) f[lastH] *= 2 — applied after the Chorus’s base value, so the doubling happens before auras and Nebula boosts are added. Not literally “double” at the end.

Text contradicts codeRelics

Prism Lens text says +2, code adds 2 and a Nebula aura tier

Text says

“A Nebula gains 2 ⭐ itself. Its neighbours still get their +2.”

Code does

Code gives the Nebula 2 fame per Prism and Nebula-adjacency is +2+T('p'), so the real gain scales with the Nebula aura tier. Text states a flat 2.

Text contradicts codeAuras

The Asteroid aura can never appear

Text says

AUR has an entry for “a”: “Destroyers shoot 1 cell farther per tier, and Asteroids and Big Asteroids appear 15% more often per tier.”

Code does

No planet has the key a, so no system can ever be dominant in it and auras() never returns it. desRg(), rockMul() and ipool() all read tierF(auras(),'a') and always get 0. If this aura is meant to work it needs a source; if not, those three functions are dead code.

Text contradicts codeAuras

Aura panel would crash if an unknown kind ever appeared

Text says

auraBox() builds its heading from K[k].n and its colour from CC[k].

Code does

K has no entry for a or q-adjacent kinds beyond the ten planets. Any aura key without a K entry throws. Harmless today only because a is unreachable — the two problems hide each other.

Text contradicts codeAuras

Nebula’s aura description does not match its effect

Text says

AUR: “+1 more growth choice at each fame goal.”

Code does

The code reads boostPicks() = 1 + tierF(auras(),'p'), so it adds choices to the find-more pick, not to growth. Different screen entirely.

Text contradicts codeAuras

Chorus aura text is right, but “counts as if 1 higher” is vague

Text says

AUR: “Each Chorus counts as if 1 higher.”

Code does

Code: x = chorusHeld() + hc + T('h') + (baton?1:0) — each Chorus’s order number is raised by the tier. Says what happens, not what it’s worth.

Text incompleteRelics

Quarry’s card omits its in-system value

Text says

Quarry: “Worth 2 ⭐, +2 for each adjacent Asteroid.”

Code does

In sysVal() a Quarry is a flat 2 with no Asteroid term at all — Asteroid adjacency only counts on the board. The card describes a bonus that stops applying the moment the Quarry joins a system.

Text incompleteRelics

Rubble Rights has no effect inside a system

Text says

“Quarries get +2 ⭐ more per adjacent Asteroid.”

Code does

sysVal() hard-codes x = 2 for Quarries, so the relic only works on the board. Same shape of problem as Quarry itself.

Text incompleteUpgrades

Starting Fleet names four kinds but the code picks any planet

Text says

“Begin each run with +1 random Verdant, Forest, Supernova or Nebula per level.”

Code does

startOffer() filters only to exclude Ice (i), Black Holes (k) and merge-stars, so Cradle, Chorus and Quarry are also possible. Text lists four; the pool is seven.

Text incompletePrestige

Prestige IX and X read as if they stack their fame penalty

Text says

IX: “Auras need 5 more points to reach their next tier.” X: “Fame goals ask for 110% more in total.”

Code does

PEFF is cumulative — each entry repeats every earlier penalty and the fame column runs 20,30,40,…,110. So IX and X also carry their own fame rise; the descriptions only name the new rule, not the running total.
